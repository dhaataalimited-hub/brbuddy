# Security

BRBuddy runs on your Mac with Accessibility access (for the terminal mirror) and talks to AI agents through local
hooks, so security reports matter to us.

## Reporting a problem
Please don't open a public issue for a security problem. Instead, either:
- use GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/dhaataalimited-hub/brbuddy/security), or
- email **hello@dhaataa.com** with "BRBuddy security" in the subject.

Include what you found, how to reproduce it and the BRBuddy and macOS versions. We'll reply within a few days and
credit you in the release notes if you'd like.

## Supported versions
Only the latest release gets fixes. BRBuddy updates itself, so most people are on it.
